# Workflow F: Off-Page Opportunities and Backlink Prospecting

**Input**: domain, industry, target URLs, optional competitors and backlink exports.
**Output**: authority strategy, verified prospect sheet (templates/backlink-prospects.csv), outreach drafts.

Load: references/off-page-seo.md.

## Checklist

```
- [ ] 1. Phase 2 brief (spam policy and link guidance changes)
- [ ] 2. Linkable asset inventory: what the site has that deserves links (data, tools, expertise, case studies); gaps to create
- [ ] 3. Current profile (only if export supplied): referring domains, anchors, toxic patterns created by the site
- [ ] 4. Competitor link gap (export) -> domains linking to 2+ competitors
- [ ] 5. Prospect discovery via search operators (off-page-seo.md); open every prospect page
- [ ] 6. Evaluate each with the 9-criterion rubric; exclude pay-to-play and link farms
- [ ] 7. Record public contact only with the URL where found; otherwise "not publicly listed"
- [ ] 8. Outreach angle per prospect tied to their audience
- [ ] 9. Personalized drafts for top prospects (not sent)
- [ ] 10. Digital PR campaign concept(s) with data source and method
- [ ] 11. QA: no prohibited tactics, no guessed contacts, every row has source URL + date
```

Prospect sheet minimum columns: publication, url, opportunity_type, target_page, why_relevant, contact, contact_source_url, outreach_angle, rubric_score, priority, verified_date, source.
