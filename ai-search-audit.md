# Workflow I: AI Search Visibility Audit

**Input**: brand, website, target queries, available analytics (GSC, GA4, Bing WMT).
**Output**: current platform guidance summary, discoverability assessment, query-level observation table, prioritized improvements, measurement plan.

Load: references/ai-search-optimization.md, references/structured-data.md. Add references/technical-seo.md for eligibility checks.

## Checklist

```
- [ ] 1. Phase 2 brief including AI features doc, AI optimization guide, Bing guidelines, and any platform the user cares about
- [ ] 2. Eligibility: robots.txt for Googlebot, Bingbot, OAI-SearchBot, PerplexityBot; snippet controls; noindex; key content in HTML text
- [ ] 3. Entity consistency: brand/product names and facts across site, GBP, LinkedIn, directories
- [ ] 4. Query set (10-30): informational + commercial + brand
- [ ] 5. Observe answers per platform (dated, market); mark "not observed" where tools lack access
- [ ] 6. Answer-gap analysis: questions without clear on-site answers; weak evidence; missing comparisons
- [ ] 7. Original data opportunities and digital PR ideas for genuine mentions
- [ ] 8. Multimodal check: images/video with metadata on key pages
- [ ] 9. Recommendations, platform-tagged (Google / Bing / ChatGPT / Perplexity / all), P0-P3
- [ ] 10. Measurement plan: GSC (Web totals, Generative AI reports if available), Bing AI Performance, GA4 AI-referrer channel group
- [ ] 11. QA: no citation promises; no llms.txt/special-schema claims for Google; sources for platform claims
```

Observation table columns: query, intent, platform, date, market, brand_cited, site_url_cited, competitors_cited, answer_accuracy_notes, observed_or_not.
