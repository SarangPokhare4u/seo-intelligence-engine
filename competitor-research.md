# Workflow: Competitor Research

**Input**: website or industry; optional named competitors, tool exports.
**Output**: competitor intelligence report with classified opportunities.

Load: references/competitor-analysis.md, references/keyword-research.md.

## Checklist

```
- [ ] 1. Phase 2 brief
- [ ] 2. Priority keyword set (10-30) from business inputs or prior keyword map
- [ ] 3. Observe SERPs (dated, market) or use tool export; tally domains -> organic competitor set
- [ ] 4. Separate business competitors vs organic-only competitors (publishers, directories, forums)
- [ ] 5. For top 3-5 organic competitors: architecture, clusters, page types, commercial vs informational coverage, conversion paths, differentiation
- [ ] 6. Keyword overlap and gaps (tool export) or observed gaps (labeled)
- [ ] 7. Referring domains only if export supplied; otherwise "not assessed"
- [ ] 8. Classify opportunities: quick wins, high-conversion, strategic gaps, improvements, long-term authority
- [ ] 9. Prioritize P0-P3; recommended action + URL per opportunity
- [ ] 10. QA + quality report
```

Output: report per competitor-analysis.md "Report structure", plus an opportunities CSV with columns `class,cluster,keyword_examples,action,target_url,priority,evidence,source,date`.
