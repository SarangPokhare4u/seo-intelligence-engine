# Workflow E: Write or Optimize a Landing Page

Covers B2B SaaS landing, product, service, homepage, comparison, use-case, industry, local service, and e-commerce category pages.

**Input**: product/service facts, audience, domain, existing page URL (if optimizing), proof assets (case studies, logos, numbers the user can substantiate), brand rules.
**Output**: keyword + SERP analysis, positioning notes, page architecture, complete copy (templates/landing-page-template.md), metadata, CTAs, schema, implementation notes, QA.

Load: references/content-writing.md, references/on-page-seo.md, references/structured-data.md.

## Checklist

```
- [ ] 1. Phase 2 brief
- [ ] 2. Buyer research: role, jobs, pains, triggers, objections, evaluation criteria, buying committee
- [ ] 3. Keyword + SERP: does the SERP reward a product page, comparison, or guide? Choose page type accordingly
- [ ] 4. Existing page review (if any): current title/H1/copy, GSC queries, conversions; preserve ranking URL
- [ ] 5. Positioning: category, differentiators the user can prove, proof inventory
- [ ] 6. Page architecture (sections in order with purpose of each)
- [ ] 7. Copy: hero (H1, subhead, primary CTA), problem, outcome, how it works, capabilities tied to jobs, proof, integrations/specs, objections/FAQ (real), final CTA
- [ ] 8. Unknown facts -> [CONFIRM: ...] placeholders, never invented
- [ ] 9. Metadata + validate_metadata.py
- [ ] 10. Internal links in/out (which cluster pages should link here, with anchors)
- [ ] 11. Schema (Organization/Product/SoftwareApplication/LocalBusiness/BreadcrumbList as eligible) + validate_schema.py
- [ ] 12. CTA plan by visitor stage; form friction notes; tracking events to add
- [ ] 13. Implementation notes: rendering, CWV for hero media, canonical, redirects if URL changes
- [ ] 14. QA + quality report
```

## Conversion rules

- One primary CTA repeated (hero, mid, end); one lower-commitment secondary CTA.
- Proof near claims. Only real, approved customer names, logos, quotes, and figures.
- Answer the top 3 objections on-page.
- For comparison pages: fair criteria, cite competitor facts from their public pages with dates, disclose that the page is published by the vendor.
