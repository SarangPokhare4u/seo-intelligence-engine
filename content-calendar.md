# Workflow J: SEO Content Calendar

**Input**: domain, audience, competitors, time horizon (e.g. 3, 6, 12 months), publishing capacity.
**Output**: prioritized editorial calendar CSV (templates/editorial-calendar.csv) + cluster rationale.

Load: references/topical-authority.md, references/keyword-research.md.

## Checklist

```
- [ ] 1. Phase 2 brief
- [ ] 2. Inputs: existing content inventory (sitemap), keyword map (or run Workflow C condensed), capacity per month
- [ ] 3. Topic map: pillars, clusters, journey stages
- [ ] 4. Decide per topic: new, refresh, consolidate
- [ ] 5. Score and order (priority score + dependencies: pillar before clusters; commercial pages before supporting posts where demand exists)
- [ ] 6. Seasonality and events (Trends, industry calendar, product launches)
- [ ] 7. Assign: target keyword, URL, buyer stage, format, CTA, internal links, owner, dependency, publish month
- [ ] 8. Balance: mix of BOFU/MOFU/TOFU suited to business goal; no near-duplicate topics
- [ ] 9. Build CSV; validate headers; summary of first 90 days
- [ ] 10. QA + quality report
```

Calendar columns: publish_month, title_working, content_type, cluster, pillar_url, target_url, primary_keyword, secondary_keywords, intent, buyer_stage, format, cta, internal_links_to, dependencies, action (new/refresh/consolidate), priority, owner, status, data_source.
