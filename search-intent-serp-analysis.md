# Search Intent and SERP Intelligence

## How to observe a SERP

- Use WebSearch or a browser tool for the target market. Record date, location/language, device if known.
- WebSearch returns organic links only; it does not reliably show AI Overviews, PAA, local packs, or ads. Only list features you actually saw; otherwise mark `features not verified (tool limitation)`.
- Rank tracker exports (Ahrefs, Semrush) can supply feature data; label the source and date. Note: since Sept 2025 Google no longer supports `&num=100`, which changed some trackers' depth.

## What to record per priority query

| Field | What to capture |
|---|---|
| Dominant intent | What most top results satisfy |
| Page types | product, category, blog, guide, tool, video, forum, directory, government, vendor homepage |
| Content depth/format | listicle, how-to, comparison table, calculator, template |
| Ranking entities | brands, publishers, forums, marketplaces |
| SERP features | only observed features |
| Freshness | dated results? year in titles? |
| Commercial signals | ads, shopping, pricing pages |
| Gaps | questions unanswered, outdated info, no first-hand evidence, no data |

## Decision rules

- **Create** when no site page matches the dominant intent and the site can credibly satisfy it.
- **Improve** when a site page matches intent and ranks 5-30 or has impressions without clicks.
- **Consolidate** when two+ site pages split the same intent.
- **Do not target** when the SERP intent conflicts with the business (e.g., consumer/government results for a B2B term), or when only marketplaces/forums rank and the site cannot offer that experience.
- **Mixed intent**: serve the dominant intent on the page; link out to a second page for the secondary intent.

## Intent shortcuts (verify with SERP)

- "what is", "how to", "guide", "examples" -> informational
- "best", "top", "vs", "alternative", "review", "comparison" -> commercial
- "pricing", "demo", "buy", "quote", "software for <task>" -> transactional/commercial
- brand + product -> navigational

## AI features in the SERP

If an AI Overview or AI Mode answer is observed, note cited sources and whether the site is cited. Do not infer AI Overview presence from studies; record observation or `unverified`.
