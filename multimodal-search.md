# Multimodal Search Optimization

Verify the current Google doc for each surface before recommending specifics.

| Surface | Key practices | Doc |
|---|---|---|
| Google Images | Descriptive file names; alt text; relevant surrounding text and captions; high-quality, original images; `<img>` elements (not CSS backgrounds) for indexable images; image sitemaps for discovery; consistent URL per image across pages (2025-05-12); image metadata (creator, license) markup; `og:image` and preferred image best practices (2026-03-02) | developers.google.com/search/docs/appearance/google-images |
| Video search | Dedicated watch page per video; VideoObject markup (name, description, thumbnailUrl, uploadDate, duration, contentUrl/embedUrl, `creator`); video sitemap; crawlable thumbnails; key moments via Clip/SeekToAction | developers.google.com/search/docs/appearance/video |
| YouTube | Title with the searched topic in natural language; description first lines carry the value; chapters; accurate captions; custom thumbnail; playlists; consistent channel topic | YouTube Help |
| Google Discover | High-quality large images (>=1200 px wide, `max-image-preview:large`); timely, people-first content; no clickbait; Discover core update Feb 2026 (see "Get on Discover" doc updated 2026-02-05) | developers.google.com/search/docs/appearance/google-discover |
| Shopping / merchant listings | Merchant Center feed + Product markup; shipping and return policies; AI-generated product images need IPTC TrainedAlgorithmicMedia metadata | Merchant Center Help |
| Google News / Top stories | News-eligible content, transparency (bylines, dates, contact), no specific markup required; Article markup helps | Google News docs |
| Social/video platforms in Search Console | Platform properties and social/video performance guide (July 2026) | Search Central Blog |

Rules: one technique does not transfer automatically across surfaces; do not keyword-stuff alt text; do not use AI images to depict real events or products deceptively.
