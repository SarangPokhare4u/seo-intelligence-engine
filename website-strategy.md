# Workflow A: New Website SEO Strategy

**Input**: domain (or planned domain), business description, audience, markets/languages. Optional: GSC/GA4 exports, competitor list, CMS.
**Output**: strategy document + keyword map CSV + content architecture + 90-day/6-month roadmap.

Load: references/keyword-research.md, references/topical-authority.md, references/technical-seo.md, references/analytics-measurement.md.

## Checklist

```
- [ ] 1. Phase 2 SEO Intelligence Brief
- [ ] 2. Business profile: model, products, ICP, buying committee, conversions, markets, constraints
- [ ] 3. Current state (if site exists): fetch homepage, robots.txt, sitemap; GSC summary if supplied
- [ ] 4. Keyword research (Workflow C, condensed): 50-200 keywords, clustered
- [ ] 5. Competitor snapshot (organic competitors for 10-20 priority terms)
- [ ] 6. Site architecture: page inventory (commercial, solution, use-case, industry, resources), URL scheme, navigation, internal linking model
- [ ] 7. Technical foundation spec: hosting/HTTPS, rendering approach, sitemaps, robots, canonical rules, CWV budget, analytics + GSC setup, structured data plan
- [ ] 8. Content plan: pillars/clusters mapped to journey stages and conversions
- [ ] 9. Off-page plan: 3-5 ethical authority initiatives tied to real assets
- [ ] 10. Measurement plan: KPI layers, dashboards, cadence
- [ ] 11. Roadmap with P0-P3 priorities, owners, dependencies
- [ ] 12. QA + quality report
```

## Output structure

1. Executive summary (5 bullets: biggest opportunities, risks, first 30 days)
2. Intelligence brief
3. Business and audience assumptions
4. Opportunity analysis (keyword clusters with priority, evidence, data sources)
5. Site architecture (table: URL, page type, primary cluster, intent, conversion)
6. Technical foundation spec
7. Content architecture and first-quarter calendar
8. Authority-building plan
9. Measurement plan
10. Roadmap (Now / Next / Later) with P0-P3
11. Quality report
